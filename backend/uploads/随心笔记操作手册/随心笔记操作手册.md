# 使用准备

## 操作系统要求

系统版本：Win7及以上；macOS10.0.4及以上

## 浏览器要求

**建议使用浏览器：Chrome**

兼容的浏览器：Microsoft Edge、Safari、360极速浏览器（等国内浏览器的极速模式）

版本要求：建议使用浏览器的最新版

## 系统访问信息

http://192.168.0.173:89/cjvision4/#

## 业务流程图

无

## 角色权限

|  |  |  |
| --- | --- | --- |
| **角色** | **菜单或应用** | **操作权限说明** |

### 详情

点击详情按钮，打开笔记详情页面。可对笔记进行撤回编辑，评论点赞操作。

![](./media/图片-031.jpeg)

### 删除、批量删除

点击删除或者勾选数据批量删除，弹出是否确定删除提示，点击确定，删除成功，点击取消，取消删除。

![](./media/图片-032.jpeg)

![](./media/图片-033.jpeg)

## 标签管理

### 标签分类

点击+分类，按要求填写数据后点击保存按钮。

![](./media/图片-034.jpeg)

#### 标签分类编辑

点击标签分类后的…，点击编辑，打开编辑分类页面，可修改标签分类名称。

![](./media/图片-035.jpeg)

#### 标签分类删除

点击标签分类后的…，点击删除按钮， 如果分类下没有编辑可删除分类，如果分类下有标签则无法删除。

### 

### 标签

选择一个标签分类后点击+标签，按要求填写数据后点击保存，标签新增成功。

![](./media/图片-037.jpeg)

#### 编辑

点击标签后的编辑按钮，可修改标签名称。

![](./media/图片-038.jpeg)

#### 删除、批量删除

点击标签后的删除，或者勾选标签点击批量删除，可删除标签。

#### 批量转移

勾选标签后点击批量转移，选择标签分类，保存后标签就转移到选择的标签分类中。

![](./media/图片-039.jpeg)

## 笔记模块

### 模块

#### 新增

点击+模块按钮，按要求填写数据后点击保存按钮。

![](./media/图片-040.jpeg)

#### 编辑

选择一个模块数据，点击数据后的编辑按钮，修改数据后点击保存按钮。

![](./media/图片-041.jpeg)

#### 删除

选择一个模块数据点击删除按钮，如果模块下有关联的笔记则提示不能删除，如果模块下没有关联的笔记，点击删除弹出是否确定删除提示，点击确定删除成功，点击取消取消删除。

![](./media/图片-042.png)
