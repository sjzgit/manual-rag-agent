# 功能名称

## 角色权限

|  |  |
| --- | --- |
| **角色** | **权限** |
| 总服药管理员 | 1. 维护全部幼儿的服药记录、服药信息； 2. 审核全部幼儿的服药申请； 3. 设置全部幼儿的服药申请的喂药教师； 4. 维护全部校区的默认喂药教师； 5. 维护申服药申请请示例图、授权书。 6. 导航页访问 |
| 分校区服药管理员 | 1. 维护负责校区下幼儿的服药记录、服药信息； 2. 审核负责校区下幼儿的服药申请； 3. 设置负责校区下幼儿的服药申请的喂药教师； 4. 维护负责校区的默认喂药教师。 5. 导航页访问 |
| 家长（幼儿账号） | 1. 查看本人全部服药记录； 2. 提交本人的服药申请； 3. 查看、撤回本人服药申请记录。 |
| 喂药教师 | 1. 查看当前学期本人为喂药教师的喂药任务； 2. 添加本人为喂药教师的喂药任务的服药记录。 |
| 班主任 | 1. 查看所带班级幼儿当前学期的服药记录。 |

## **名词解释**

|  |  |
| --- | --- |
| **名词** | **解释** |
| 示例图 | 1. 服药申请的一部分，用于提示家长上传图片的要求。 |
| 授权书 | 1. 服药申请的一部分，用于家长授权学校给幼儿喂药； 2. 可与服药记录一同导出。 |
| 喂药教师 | 1. 由服药管理员指派的负责记录服药记录的教职工。 |
| 默认喂药教师 | 1. 为方便服药管理员指派喂药教师，预先设置特定教职工为默认的喂药教师； 2. 每个校区预计有5个左右喂药教师。 |
| 服药申请 | 1. 家长提交的幼儿服药申请； 2. 喂药任务的必要数据来源。 |
| 喂药任务 | 1. 根据审核通过的服药申请，自动生成多条任务； 2. 由喂药教师、服药管理员在任务中添加服药记录。 |
| 服药记录 | 1. 由喂药教师、服药管理员在喂药任务下添加的按时服药/未按时服药/未服药记录。 |
| 应出勤日 | 1. 幼儿应到校的日期，取校历中无【休息】的【教学】日期； 2. 服药日期包含多日期的，仅就其中包含幼儿应到校的日期生成喂药任务。 |

### **申请服药**

![](./media/图片-011.png)

![](./media/图片-012.png)

**操作说明：**

1. 点击添加【药品】按钮，在按钮上方插入新的【药品信息】卡片；
2. 点击【删除】按钮，删除该【药品信息】卡片，至少保留1个【药品信息】卡片；
3. 点击【病历处方】图片上传按钮，批量上传图片；
4. 点击【下一步】按钮，进入【授权签字】页。

**数据说明：**

1. 【联系电话】输入框为必填，11位手机号；
2. 【病症】输入框为必选，多选，选项取晨检功能数据；
3. 【就诊医院】输入框为必填，文本输入，最多20字；
4. 【诊断结果】输入框为必填，文本输入，最多20字；
5. 【服药日期】选择器为必选，日期范围，日期范围内至少包含1个应出勤日；
6. 【药品】名称输入框为必填，文本输入，最多20字；
7. 【用法】名称输入框为必填，文本输入，最多20字；
8. 【用量】名称输入框为必填，文本输入，最多20字；
9. 【服用时间】名称输入框为必填，文本输入，最多20字；
10. 【病历处方】图片为必传，图片数量不少于示例图数量；

【备注】输入框为选填，文本输入，最多20字。
