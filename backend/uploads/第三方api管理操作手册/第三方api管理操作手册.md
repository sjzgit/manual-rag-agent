# 第三方api管理

### 开发者管理

#### 新增、编辑

1、新增开发者账号，开发者登陆账号为：账号名称@dev，密码：账号名称@pwd

![](./media/图片-012.png)

![](./media/图片-013.png)

#### 重置密码

1、可重置密码为：账号名称@pwd

![](./media/图片-014.png)

#### 删除、禁用

1. 可删除、禁用账号，删除、禁用后账号不能登陆使用。

![](./media/图片-015.png)

### 接口管理

1. 可新增/删除，启用/禁用接口，禁用后接口不能调用。
2. 该页面数据来源于开发提测sql，不需要自己创建。

![](./media/图片-016.png)

![](./media/图片-017.png)

### 错误代码

1. 可新增、删除、查看错误代码，该页面数据来源于开发提测sql，不需要自己创建。

![](./media/图片-018.png)

### 园部列表

1、可查看租户及园部id代码。

![](./media/图片-019.png)

### 应用管理

#### 新增、编辑

1、可新增/编辑查看应用。

![](./media/图片-020.png)

![](./media/图片-021.png)

![](./media/图片-022.png)

#### 授权

1. 点击授权按钮，进入授权界面。

![](./media/图片-023.png)

##### 接口授权

1、点击新增接口授权，给应用添加授权可调用的接口；设置每日次数限制，可限制该应用下的接口调用次数；设置禁用接口后，该接口不可调用。

![](./media/图片-024.png)

![](./media/图片-025.png)

##### 园部授权

1、点击新增园部授权，授权可调用接口的园部；设置禁用园部后，该园部不可调用接口。

![](./media/图片-026.png)

![](./media/图片-027.png)

#### 删除、禁用/启用

1、可删除、禁用/启用应用，禁用后应用中的接口不能被调用。

![](./media/图片-028.png)

![](./media/图片-029.png)
