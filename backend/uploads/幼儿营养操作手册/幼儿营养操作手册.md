## 具体操作说明

### 后台系统

#### **食物分组**

1. 【食物分组】页默认选中【全部食物】选项。
2. 【食物分组】页默认选中【全部食物】选项。
3. 选中食物分组选项，显示该分组下食物的【食物分组】表格
4. 食物分组】表格显示食物名称、分类-亚类、食物分组，食物名称固定显示；
5. 【食物分组】表格固定显示食物名称
6. 【食物分组】表格根据食物编号升序排序，分页显示

![](./media/图片-003.png)

##### 导入

1. 点击【导入】按钮，下载/导入【食物分组导入模版】
2. 下载【食物分组导入模版】时，带出当前食物分组数据
3. 导入模版中有数据的，覆盖原数据

![](./media/图片-004.png)

##### **批量设置分组**

##### **设置分组**

1. 【膳食宝塔食物组】选择器显示【移出分组】按钮
2. 点击【移出分组】按钮，从【膳食宝塔食物组】移出食物
3. 【食物类别】、【热量食物来源】、【蛋白质食物来源】、【微量元素食物来源】选择器为必选，单选；
4. 【膳食宝塔食物组】选择器为非必选，单选

![](./media/图片-005.png)

#### **食物成分表**

1. 【食物成分表】页默认选中第一个版本标签
2. 点击版本标签，切换显示【食物成分表】表格；
3. 状态为关闭的版本，版本标签显示“（关闭）”
4. 可根据食物名称/食物拼音首字母/食物编号搜索【食物成分表】表格；
5. 【食物成分表】表格显示食物编号、食物名称、食物分类、食物亚类、食物成分，食物编号、食物名称固定显示
6. 【食物成分表】表格根据食物编号升序排序，分页显示

![](./media/图片-006.png)

##### 新增

1. 新建版本状态默认为关闭，版本下食物成分数据默认为0；
2. 点击【添加】按钮，显示【创建版本】对话框，输入【版本名称】创建版本

![](./media/图片-007.png)

##### **导入**

1. 点击【导入食物成分】按钮，下载/导入【食物成分表导入模版】；
2. 下载【食物成分表导入模版】时，带出版本当前食物成分数据；
3. 导入模版中有数据的，覆盖原数据

![](./media/图片-008.png)

#### **幼儿营养标准**

1. 【幼儿营养标准】页默认选中第一个版本标签
2. 点击版本标签，切换显示【幼儿营养标准】表格
3. 点击【添加】按钮，显示【创建版本】对话框，输入【版本名称】创建版本
4. 状态为关闭的版本，版本标签显示“（关闭）”
5. 【幼儿营养标准】表格显示统计项、托班标准、小班标准、中班标准、大班标准、最后编辑时间，统计项固定显示
6. 【幼儿营养标准】表格默认根据统计项排序，可根据最后编辑时间排序，分页显示
7. 新建版本状态默认为关闭，版本下统计项数据默认为0；

![](./media/图片-009.png)

##### 编辑

1. 编辑后保存即可
2. 数量大于0.1
3. 参与统计的班级在基础数据的年级管理设置

![](./media/图片-010.png)

#### **电子秤设置密码**

1、密码设置为6位、同步修改电子秤apk登录密码

![](./media/图片-011.png)

### 校级

#### 引导页

1. 营养分园管理员进入的，不显示【基础设置】卡片
2. 卡片显示当天选中校区食谱包含菜品（去重）数量、当天食谱包含食材（去重）数量、当天用餐人数
3. 卡片显示当前教学周及上月热量摄入量占建议量比值；
4. 卡片显示当前教学周及上月蛋白质摄入量占建议量比值
5. 卡片显示当前教学周及上月动物性食物+豆类食物包含蛋白质占总蛋白质比值
6. 卡片显示当前教学周及上月动物性食物+豆类食物产生热量占总热量比值
7. 卡片显示当前教学周及上月蛋白质：脂肪：碳水化合物摄入量比值
8. 卡片显示当前教学周及上月蛋白质产生热量占总热量比值；
9. 卡片显示当前教学周及上月脂肪产生热量占总热量比值
10. 卡片显示当前教学周及上月碳水化合物产生热量占总热量比值
11. 点击【导出】按钮，导出本周/本月营养分析报告

#### 食物成分表

1. 营养分园管理员进入的，不显示【切换版本】按钮、食物状态
2. 营养分园管理员进入的，仅显示开启状态的食物
3. 点击【切换版本】按钮，提示确认后，幼儿园使用选中版本
4. 切换版本后，当天及未来的营养元素摄入量取切换后版本
5. 关闭食物【状态】时，提示确认“包含关闭食物的菜品将被关闭”，确认后关闭食物，并关闭包含该食物的菜品
6. 关闭食物后，不能在【菜品管理】、【每周食谱】、【食材记录】中添加该食物

![](./media/图片-019.png)

#### 幼儿营养标准

1. 营养分园管理员进入的，不显示【统计餐别】标签、【切换版本】按钮
2. 【统计餐别】标签页点击【营养标准】标签
3. 点击【切换版本】按钮，提示确认后，幼儿园使用选中版本
4. 切换版本后，营养统计标准取切换后版本

![](./media/图片-020.png)

#### 食物分组

1. 默认选中【全部食物】。
2. （二级）食物分组显示分组下包含（开启）食物数量
3. 选中【全部食物】选项，显示全部食物的【食物分组】表格
4. 可根据食物名称/食物拼音首字母/食物编号搜索【食物分组】表格；

![](./media/图片-022.png)

#### 菜品管理

1. 营养分园管理员进入的，不显示【导入菜品】、【标签管理】按钮、分类【添加】按钮、批量【设置分类】按钮、【更多操作】按钮、菜品【状态】、分类【更多】按钮、【菜品评价】开关
2. 营养分园管理员进入的，点击【菜品】表格菜品名称，仅对话框查看菜品详情，不能编辑
3. 新增菜品时，菜品【状态】默认为开
4. 选中【全部菜品】/【未分类】/菜品分类选项，显示分类下【菜品】表格
5. 【全部分类】/【未分类】/食物分类显示分类下开启菜品数量
6. 可根据菜品名称/包含食材搜索【菜品】表格
7. 悬停食材数量，气泡显示菜品包含食材
8. 【菜品】表格可根据使用次数、获赞次数、被踩次数升序/降序排序

![](./media/图片-023.png)

##### 新增菜品

1. 点击【添加菜品】按钮，对话框新增菜品
2. 点击对话框【保存并继续】按钮，保存菜品并继续新增
3. 【菜品名称】输入框为必填，文本输入，最多20字，不能与现有菜品重名
4. 【菜品标签】选择器为非必选，多选
5. 【菜品照片】为非必传
6. 【备注】输入框为选填，文本输入，最多100字

![](./media/图片-024.png)

1. 点击【标签管理】按钮，进入【标签管理】页
2. 最多输入10字

4. 【标签】表格显示标签名称、包含菜品数量、标签状态、排序按钮

6. 表内编辑标签名称
7. 点击【删除】按钮，提示确认后，可批量删除选中的标签

3. 删除分类的，分类下菜品分类变更为【未分类】

#### 每周食谱

1. 总园长/分园长进入的，不显示【导出】按钮、【复制食谱】按钮、【添加】按钮、【编辑】按钮、【删除】按钮
2. 默认选中用餐周第一个日期标签
3. 添加菜品、水果时，【用餐学龄段】复选框默认全选
4. 卡片显示选中用餐周食谱包含菜品（去重）数量、食材（去重）数量、热量摄入量占建议量比值、蛋白质摄入量占建议量比值、碳水化合物摄入量占建议量比值
5. 选中日期标签，显示日期下【带量食谱】表格、【特殊膳食】表格
6. 用餐学龄段非全部学龄段的，菜品显示用餐学龄段
7. 特殊膳食的食材重量也会计算到统计去
8. 用餐周日期下没有食谱记录的，日期标签显示标记

![](./media/图片-029.png)

##### **添加食谱**

1. 点击早点/午餐/午点【添加】按钮，对话框批量添加菜品，该天该餐别已添加的菜品不能重复添加

3. 点击水果【添加】按钮，对话框添加【水果及制品】分类下开启的食物、用量、用餐学龄段
4. 【用餐学龄段】复选框至少选中一个
5. 只能维护当天及未来的食谱数据
6. 用餐周取选中学年学期教学周数据

![](./media/图片-030.png)

###### 添加水果

1. 【水果】选择器为必选，单选，选项为【水果及制品】分类下的食物
2. 【用量】输入框为非必填，（0-1000]，精确到0.1
3. 【用餐学龄段】复选框至少选中一个（默认全选）
4. 可以查看分餐比例

![](./media/图片-031.png)

###### **添加调味品**

1. 【调味品】选择器为必选，单选，选项为【调味品类】分类下的食物
2. 【用量】输入框为非必填，（0-1000]，精确到0.1
3. 可以查看分餐比例
4. 可以多次添加多种调味剂
5. 调味剂添加时不可重复添加

![](./media/图片-032.png)

###### **添加特殊膳食**

1. 特殊膳食【菜品名称】输入框为必填，文本输入，最多20字
2. 特殊膳食【膳食类型】为必选，单选，选项为（分租户）字典表维护
3. 【备注】为选填，文本输入，最多20字

![](./media/图片-033.png)

##### 食材清单

1. 卡片显示预计用餐人日
2. 点击编辑按钮，气泡编辑预计用餐人日
3. 显示平均单日（预计）用餐人数
4. 卡片显示食物类别下包含食物（去重）数量、食物名称、（预计）食物总用量
5. 调整预计用餐人日影响食材清单、食材记录表、食谱营养分析
6. 用餐天数为有菜品记录的天数

![](./media/图片-034.png)
