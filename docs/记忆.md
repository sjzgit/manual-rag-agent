# 会话记忆

1. 我们认为一个会话一般对应某一个功能的操作手册，所以首次对话结束后，我们会将检索到的操作手册完整内容保存到会话记忆中，下次对话时，LLM会结合上下文和当前会话记忆的操作手册内容判断：如果还在当前文档范围内则直接进行回答，无需检索。否则再走检索流程。
2. 当然我们也允许用户在单个会话中触发多个操作手册文档，我们需要设置会话记忆中关联的文档上限，不超过这个上限是都可以保存到会话记忆中。这样可以提高问答效率，节省频繁检索相同文档。
3. 给LLM的会话上下文中包含：
   1. 用户输入&LLM输出的内容
   2. 会话记忆中保存的操作手册内容
   3. 不包含：思考过程、检索到的切片
4. 这里保存的操作手册应该是存id，而不是存内容。避免文档内容变化或被删除失效后会话中还保留历史文档内容。所以存id，每次检索时再查内容添加到上下文中。不过可以做个短期redis缓存，避免频繁查询。
